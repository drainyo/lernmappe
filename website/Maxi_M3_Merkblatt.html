2. Das unsichtbare „hoch 1“ und die Zahlen davor

  • a = a1. Deshalb: a · a2 = a1+2 = a3.
  • Bei Termen mit Zahl davor: Zahlen mal Zahlen, Buchstaben mal Buchstaben.
    −4a · 5a2 = (−4 · 5) · (a1 · a2) = −20a3
    2a4 · 5 · a2 = (2 · 5) · a4+2 = 10a6
  • Klammer hoch: alles in der Klammer wird hoch genommen, auch die Zahl.
    (2y)3 = 23 · y3 = 8y3 · (−3x)2 = 9x2 · (5de)2 = 25d2e2
  • Kürzen: Zahlen kürzen, Hochzahlen abziehen. (6a2)2 / (9a) = 36a4 / 9a = 4a3

3. Vorzeichen bei Potenzen

  • Negative Basis, gerade Hochzahl → plus: (−2)4 = 16, (−1)100 = 1
  • Negative Basis, ungerade Hochzahl → minus: (−3)3 = −27, (−1)7 = −1
  • Ohne Klammer gehört das Minus nicht dazu: −24 = −16

5. Primfaktorzerlegung in Potenzschreibweise

Divisionskette wie im Heft (3.11.), dann gleiche Faktoren als Potenz zusammenfassen:

392 : 2 = 196 : 2 = 98 : 2 = 49 : 7 = 7 : 7 = 1 → 392 = 2 · 2 · 2 · 7 · 7 = 23 · 72

Nur Primzahlen (2, 3, 5, 7, 11 …) dürfen stehen. Probe: ausrechnen, muss wieder die Zahl ergeben.

6. Flächeninhalt Dreieck

  • A = c · hc : 2 (Seite mal dazugehörige Höhe durch 2)
  • Rechtwinklig: A = a · b : 2 (die zwei Katheten)
  • Höhe gesucht: hc = 2 · A : c
  • Stumpfwinkliges Dreieck: Die Höhe liegt außerhalb, weil der stumpfe Winkel die Seite „wegkippt“. Die Höhe trifft auf die Verlängerung der Seite. Die Formel gilt trotzdem.
  • Zusammengesetzte Figur: alle Teile ausrechnen und addieren (Rechteck + Dreieck).
  • Sachaufgabe mit Kübeln, Dosen, Platten: immer aufrunden (3,6 Kübel → 4 Kübel).
  • Veränderungen: Höhe · 2 → Fläche · 2 · c und h je · 2 → Fläche · 4 · c : 3 und h · 3 → Fläche bleibt gleich.
